WHY I BUILT IT

VoltCalc started as a simple calculator I built out of curiosity while I was learning JavaScript.

What began as a basic experiment kept growing as I learned more about DOM manipulation, browser storage, responsive design and application architecture.

Instead of throwing the original project away, I kept upgrading it as I learned.

Today it has grown into a much more complete utility system with scientific calculations, history, conversion, graphing and offline support.

It is still something I can improve, and that is part of the point.

I want to be able to return to this project later and see how much better I have become.

ORIGIN: Curiosity + learning EVOLUTION: Continuous upgrades GOAL: Build better products
